# Load Analysis

This section documents the estimated electrical loads used to size the portable PV system.

## Load Calculation Method

Each load is evaluated using:

- Power rating in watts
- Estimated hours of operation
- Daily energy consumption in watt-hours

## Formula

```txt
Energy (Wh) = Power (W) x Time (h)
```
