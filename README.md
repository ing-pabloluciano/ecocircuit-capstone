# EcoCircuit - Portable PV System

EcoCircuit is a portable photovoltaic system project focused on solar energy, electrical systems, power flow, component sizing, sustainability, and technical documentation.

This repository documents the design, calculations, component selection, presentation material, diagrams, and visual evidence related to the development of a portable PV system.

## Project Overview

EcoCircuit explores the design of a portable solar power system capable of supporting small electrical loads using photovoltaic generation, energy storage, and power conversion components.

The project applies concepts from electrical engineering, renewable energy systems, load analysis, PV sizing, battery sizing, inverter selection, safety considerations, and technical documentation.
